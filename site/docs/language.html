Language tour

Everything on this page runs on the current release.

Variables and constants

const LIMIT = 10           // compile-time constant
let name = "Ada"           // immutable, type inferred (Text)
var visits = 0             // mutable
visits += 1
let ratio: Float = 0.75    // annotations are optional

Built-in types: Int (64-bit), Float, Bool, Text, Unit, List<T>. There are no implicit conversions: use .to_float(), .to_int(), .to_text(). Statements end at a newline; there are no semicolons to forget.

Functions

fn greet(name: Text, excited: Bool = false) -> Text {
    if excited { "Hello, {name}!" } else { "Hello, {name}." }
}

print(greet("Ada", excited: true))   // named arguments, defaults

The last expression is the result. if, match and blocks are expressions. Strings interpolate with {expr}.

Structs and methods

struct User {
    id: Int
    name: Text
    email: Text?
}

impl User {
    fn label(self) -> Text { "{self.name} (id {self.id})" }
    fn rename(mut self, new_name: Text) { self.name = new_name }
}

var u = User(id: 1, name: "Ada", email: none)
u.rename("Ada Lovelace")
let v = u with { email: "ada@example.org" }   // u is unchanged

Structs are values: assigning or passing one never aliases it. Methods take self (read-only) or mut self, and the compiler refuses to modify through a read-only receiver.

Enums and pattern matching

enum Food {
    Fresh(days: Int)
    Pantry
}

fn describe(f: Food) -> Text {
    match f {
        Fresh(d) if d <= 1 => "eat it today"
        Fresh(d) => "good for {d} days"
        Pantry => "keeps forever"
    }
}

match must be exhaustive for enums, Bool and optionals. Patterns support payload bindings, guards, literals, ranges (1..=9), alternatives (A | B) and wildcards.

No null: optionals

let email: Text? = none
let shown = email ?? "no email"          // default
let boss_name = person.boss?.name        // safe access: Text?
if let e = email { print("mail {e}") }   // unwrap safely
match email {
    none => print("nothing")
    some(e) => print(e)
}

A T? cannot be used where a T is required. The compiler tells you to use ??, if let or ! (which panics on none).

Loops and lists

var total = 0
for i in 1..=10 { total += i }            // ranges

var xs: List<Int> = []
xs.push(3); xs.push(4)
for x in xs { total += x }
let third = xs.get(2)                     // Int? (never panics)
loop { break }
while total > 0 { total -= 10 }

Lists are values too (copy on write). xs[i] panics when out of range; xs.get(i) returns an optional.

Tests

test "greeting" {
    assert(greet("Ada") == "Hello, Ada.")
}

Run them with jax test. Tests live next to the code they check.

Built-ins

NameMeaning
print(x)Print an Int, Float, Bool or Text followed by a newline
assert(cond), panic(msg)Abort the program with a stack trace (exit code 101)
text.len(), list.len()Length (characters for text)
list.push(x), list.get(i)Append; checked access
x.to_text(), n.to_float(), f.to_int(), f.sqrt()Conversions and math
Not yet available: generics, trait bounds, closures, Result with ?, async, maps, tuples and multi-file modules. They parse, and the compiler reports E0900 ... is not supported yet rather than miscompiling. See status.
