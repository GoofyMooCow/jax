Getting started

Install Jax, make a project, run it and ship it, in about two minutes.

Install

Linux and macOS

curl -fsSL https://goofymoocow.github.io/jax/install.sh | sh

Windows (PowerShell)

irm https://goofymoocow.github.io/jax/install.ps1 | iex

The installer downloads the launcher (jax, under 1 MB), checks its SHA-256, puts it in ~/.jax/bin (%LOCALAPPDATA%\Jax\bin on Windows), adds that folder to your PATH, and installs the latest toolchain. Open a new terminal afterwards so the PATH change takes effect.

Installer options for Linux and macOS go after sh -s --, for example curl -fsSL https://goofymoocow.github.io/jax/install.sh | sh -s -- --no-toolchain. They are --no-modify-path, --no-toolchain and --version X.Y.Z. On Windows set JAX_NO_MODIFY_PATH, JAX_NO_TOOLCHAIN or JAX_VERSION before running.

Read before you run. Piping a script into a shell trusts the server. The scripts are short: install.sh and install.ps1. Both verify the launcher's checksum before installing it.

Your first project

$ jax new hello
$ cd hello
$ jax run
Hello, Jax!

That created:

hello/
  jax.toml        the manifest: name, version and the exact toolchain
  src/main.jax    your program
  .gitignore
fn main() {
    print("Hello, Jax!")
}

The manifest pins the toolchain the project was created with:

[project]
name = "hello"
version = "0.1.0"
kind = "app"
jax = "0.1.0"   # exact toolchain version; ranges are not allowed

Build and ship

$ jax build
Built build/linux-x64/hello (linux-x64, 421.9 KiB)
$ ./build/linux-x64/hello
Hello, Jax!

The result is one self-contained file. Copy it to another machine of the same platform and it runs without Jax installed.

  • jax build --bundle writes a portable .jxb that any Jax runtime can run.
  • jax build --target windows-x64 cross-builds when the installed toolchain includes that runtime.

Commands

CommandWhat it does
jax new <name> [--lib]Create a project in a new folder
jax initCreate a project in the current folder
jax check [file]Type-check without producing output
jax run [file]Compile and run a project or a single .jax file
jax build [file]Make a standalone executable (--target, --bundle, -o)
jax test [file]Run test "name" { ... } blocks
jax dump tokens|ast|bytecode <file>Inspect what the compiler sees
jax toolchain ...Manage installed toolchains (details)

Uninstall

Everything lives in one folder. Delete ~/.jax (or %LOCALAPPDATA%\Jax) and remove the line the installer added to your shell profile (or the folder from your user PATH on Windows).

Building from source

You need Rust 1.75 or newer and nothing else. The workspace has no third-party dependencies.

git clone https://github.com/GoofyMooCow/jax
cd jax
cargo test --workspace      # unit and end-to-end tests
cargo xtask dist            # writes ./dist: launcher + toolchain archive
JAX_DIST_URL=file://$PWD/dist ./dist/bin/linux-x64/jax new hello

Replace linux-x64 with your platform (macos-arm64, windows-x64, ...). On Windows use a file:///C:/path/to/dist URL.
