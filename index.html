Write it once.
Move it anywhere.

Jax is a small, readable, strongly typed language built around one idea: a project should be easy to move, easy to rebuild years later, and easy to hand to people who have never heard of Jax.

Get startedTour the language
$curl -fsSL https://goofymoocow.github.io/jax/install.sh | sh

Installs the launcher into ~/.jax/bin, adds it to your PATH and downloads the latest toolchain. Needs curl.

>irm https://goofymoocow.github.io/jax/install.ps1 | iex

Run in PowerShell. Installs into %LOCALAPPDATA%\Jax and adds it to your user PATH. No administrator rights needed.

$git clone https://github.com/GoofyMooCow/jax && cd jax && cargo xtask dist

Needs Rust 1.75+. There are no other dependencies. See Building from source.

Readable, with the checks you want

Types are inferred inside functions. Enums and match are exhaustive. There is no null: a value that may be missing says so in its type.

enum Shape {
    Circle(radius: Float)
    Rect(width: Float, height: Float)
    Point
}

fn area(s: Shape) -> Float {
    match s {
        Circle(r) => 3.0 * r * r
        Rect(w, h) => w * h
        Point => 0.0
    }
}

fn main() {
    let big = Shape.Rect(width: 2.0, height: 3.0)
    print("area is {area(big)}")
}
$ jax new shapes && cd shapes
$ jax run
area is 6.0

Portability is the whole point

Every part of Jax is designed so that a project behaves the same on your laptop, a friend's machine and a build server, today and in ten years.

Pinned toolchains

Every project says exactly which Jax it uses: jax = "0.1.0". Ranges are rejected on purpose. Upgrading one project never touches another.

Automatic downloads

Run a project and the launcher fetches any missing toolchain, verifies its SHA-256, installs it atomically and caches it. Versions live side by side.

One-file executables

jax build produces a single file that runs on machines with no Jax installed. Cross-build with --target.

No dependencies, no setup

The whole toolchain is built with zero third-party crates, so bootstrapping is reproducible and works offline.

One command

Create, check, build, run and test with a single jax tool. Errors show the source line and suggest fixes.

Capsules planned

Self-contained project archives with dependencies, tools and even the toolchain inside, so a project can be rebuilt with no network at all.

How it works

Two small pieces: a launcher you install once, and toolchains that come and go on demand.

The project decides

jax.toml pins the exact toolchain version, and it is committed with your code.

The launcher fetches

The tiny jax launcher finds that version, downloading and verifying it first if it is missing.

You ship one file

jax build embeds your program in a runtime stub: a standalone executable for each platform.

Honest status

Jax is at stage 0. The language core, toolchain manager and build pipeline work end to end, and plenty is still ahead.

Works today

Functions, structs, enums, pattern matching, optionals, lists, tests, the launcher, automatic toolchain install, standalone builds, and good diagnostics.

Not yet

Generics, traits, closures, Result and ?, async, modules across files, the package manager and capsules. Also: programs run on a bytecode VM, not native machine code yet.
